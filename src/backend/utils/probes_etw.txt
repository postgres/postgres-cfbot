# probes_etw.txt
#      ETW keyword, level and field names for the static probes
#
# Copyright (c) 2026, PostgreSQL Global Development Group
#
# probes.d has the argument types of each probe but nothing ETW-specific.
# This file gives, for each probe, the keyword and level its event is
# written under and a name for each argument.  The arguments are written
# as in a C prototype, with their types, and Gen_etw_probes.pl fails if
# the probe set or any argument's type differs from probes.d, so a change
# to probes.d needs a matching change here.  The field names are taken
# from the argument descriptions in doc/src/sgml/monitoring.sgml.
#
# Each non-comment line has these whitespace-separated fields:
#
#   <probe-name>  <keyword>  <level>  [type field-name, ...]
#
#   probe-name   as in probes.d, double underscores and all
#   keyword      QUERY, TRANSACTION, LOCK, BUFFER, STORAGE, WAL, CHECKPOINT
#                or SORT (the PG_KW_* bits in pg_trace_etw.h)
#   level        INFO or VERBOSE
#   arguments    one "type field-name" per argument, in probes.d order and
#                comma-separated; omitted for probes with no arguments
